# v2 草稿档案

拟选 Alpha Factory → rToken 因子策略。项目：rToken Breakout Lab。

## 1. 思路
股票代币的趋势机会必须经过成本、波动、成交容量与退出条件检验。我们实现四资产现货突破、连续确认、波动缩仓与止损，不依赖LLM生成交易方向。信号基于已完成四小时行情，交易在后续分钟发生。最终规则与所有优化尝试均公开。

## 2. 目标用户与价值
面向验证小额rToken方向策略的量化开发者和小型研究团队；示例账户10000USDT，单标的初始目标上限20%，低频决策。价值是把信号、实际可模拟成交、费用与不合格证据连起来，并支持独立复现。
