# 数据与方法（含 v2 历史方法）

运行前完整协议：[protocol.json](../reports/v2/protocol.json)。源代码与运行时快照均可核验。

## 信号与成交

分钟时间戳表示开始，先加一分钟才能成为已完成行情。四小时桶至少包含60个成交量非零分钟，最后行情距桶结束不超过5分钟；滚动日历窗口至少75%的桶有效。突破阈值排除当前桶，连续确认只使用连续已完成的桶。信号不能在产生它的分钟成交。

单边高低价加滑点并按1%分钟成交量限制成交。买单30分钟到期，卖单持续等待行情；数量步长0.01和最低买入5USDT是假设。四标的共享现金，买入检查余额，不借币、不加杠杆。波动代理使用最近18根四小时收益、至少12个连续相邻有效收益；目标日波动代理2%，只能缩仓不放大。

## 回测与基准

账户初始10000USDT，闲置现金利息为零。等权持有目标每标的20%，QQQ或SPY单资产基准目标80%；也受买单超时、成交量和缺口影响，所以实际持仓未必达到目标。策略缩仓导致风险暴露不同。基准详细损益和平均持仓列在报告中。

日收益按UTC日末净值计算，Sharpe/Sortino按365天年化；不足30天不显示年化指标。记录滚动30天Sharpe、最大回撤、换手、胜率、逐笔费用。平价估值的缺失时段可能低估波动和回撤，相关分钟数另列。收益不是分红再投资后的总回报。

## 选择与门槛

本轮预设8组，先评估训练与高成本训练。严格稳健性要求至少5笔交易、前后30天均正、剔除最大盈利交易仍正、期末平仓且未触发账户停止。若无严格合格方案，可从两种成本都盈利且至少5笔的候选中按高成本Sharpe选一个**诊断版本**；若仍无则使用原始控制组。此更改在本轮结果前写入协议，未把诊断选择冒充稳定性通过。

冻结版本：`breakout-exit6-stop4-confirm2`；用途：`diagnostic_only_failed_robustness`。训练选择存在偏差。此前团队材料及旧研究曾暴露部分历史留出信息，30天留出不能称完全未触碰盲测。留出后不再调参、不换候选。本仓库保留负结果。

## 仍待验证

数据缺口无法全部区分市场休市、发行商停牌和采集失败；现货价格/成交量单位、历史交易规格、手续费等级、分红拆股等公司行动没有独立历史认证。纸面止损可能跨越缺口，无法保证止损价成交。平台盘口、排队和真实大单冲击未建模。

报告展示股票代币现货研究，未使用普通美股价格替代实际成交。rToken定义依据 [Bitget Reality交易指南](https://www.bitget.com/docs/uta/reality-trading-guide)。


## 换行与数据哈希

GitHub原始文件采用LF，本研究最初Windows检出采用CRLF。`data/sources.json`同时记录上游字节哈希与实际研究输入哈希。下载脚本先核验上游原始字节，再转换换行以复现原输入；价格、时间和成交量不变。仓库禁用自动换行转换以保持报告哈希。
